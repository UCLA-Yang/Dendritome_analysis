Main components of Dendritome analysis in below folders:
- P56 morphometric analysis: regional and D1 vs. D2 MSN morphological differences in P56 dataset
- 12m vs. P56 morphometric analysis: regional and 12m vs. P56 WT MSN morphological differences
- HD (Q140) vs. WT morphometric analysis: regional and 12m HD (Q140) vs. 12m WT MSN morphological differences
- P56 box-based analysis: box-based analysis using MSNs from P56 dataset
- Additional Analysis for Dendritome: additional analysis included in the Dendritome project
- Functions: necessary customized functions for WGCNA
- Data: processed datasets

[The interactive dashboard for viewing clusters from box-based analysis](https://yang-lab-ucla.shinyapps.io/Striatal-MSN-Dendritome-Box-Analysis-Dashboard/)
